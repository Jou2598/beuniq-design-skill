## What is BeUniq? 🔍

BeUniq helps you improve the quality of your website code. Many AI tools create generic designs that look and sound repetitive. This tool checks your project files to find those common patterns. It acts as a set of rules for your coding assistant. By using BeUniq, you ensure that your design direction stays consistent. 

The software keeps your project goals in place. It uses specific files called `PRODUCT.md` and `DESIGN.md` to track your instructions. This prevents your AI assistant from forgetting your preferences during long projects. BeUniq runs directly on your machine. It does not send your data to external servers or cloud services. 

## How It Works 🛠️

BeUniq inspects your code without needing to run it. It looks at your CSS, HTML, and React files to find indicators of low-quality AI output. It evaluates three areas:

1. AI Slop: This covers repetitive design choices.
2. Copy Slop: This covers generic marketing text.
3. Taste: This covers the overall quality of your layout and styles.

The tool provides a score from 0 to 100 for each section. A project reaches the finish line when your scores stay at or below 20. It currently supports React, Next.js, Vite, and standard web files like SCSS and Tailwind.

## Using the Software 📋

Once installed, open the BeUniq application from your Start menu. The main interface allows you to select your project folder. 

1. Click the "Open Project" button.
2. Navigate to the folder that contains your website code.
3. Click "Scan". 

The tool will analyze your files and display a report. If it finds issues, the report highlights the specific lines of code that need attention. You can then update your files and click "Scan" again to check your progress.

## Maintaining Your Workflow 📝

To get the best results, place a `PRODUCT.md` file in your root folder. Describe your vision for the project here. Do the same with `DESIGN.md` for specific style rules. The BeUniq engine reads these files to understand your requirements. This ensures the output remains unique and original.

## Frequently Asked Questions ❓

Does this tool send my code to the cloud?
No. BeUniq runs entirely on your local computer. It does not connect to external servers or AI endpoints.

What languages does the tool support?
It works with any project using React, Next.js, or standard web components like CSS and Tailwind.

Can I run this on a Mac?
This version is designed specifically for Windows.

What if my score is high?
A high score means the tool found many generic patterns. Read the feedback provided in the report to see which rules were triggered. You may need to manualy refine your styling or copy to lower the score.

## Troubleshooting 🔧

If the application fails to open:
1. Verify your download is complete.
2. Check that you have administrative rights on your computer.
3. Update your Windows system files.

If the scan stops:
1. Ensure your project files are not currently open in another program that might lock them.
2. Check that your project folder structure is valid.
